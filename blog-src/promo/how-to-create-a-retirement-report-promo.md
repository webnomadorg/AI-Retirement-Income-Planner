## Newsletter Summary


The report workflow in the AI Retirement Income Planner turns a plan into a readable planning snapshot. Update inputs first, review Plan Health and Plan Confidence, add notes, open report preview, check the assumptions, then print or save as PDF through the browser. Use JSON export separately when you want an editable backup. Optional AI commentary can help explain the report when configured, but it should always be reviewed.
